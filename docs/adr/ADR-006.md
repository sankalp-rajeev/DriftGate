# ADR-006: Compose existing tools (ggufdoctor, llama-perplexity, MET)

Status: Accepted, 18 November 2026

## Context

Time; attribution; contribution is calibration.

## Decision

Compose existing tools (ggufdoctor, llama-perplexity, MET).

## Alternative rejected

Reimplement detectors.

## Consequences

- Time.
- Attribution.
- Contribution is calibration.
