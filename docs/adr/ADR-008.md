# ADR-008: EC2 build host driven by SSM Run Command

Status: Accepted, 18 November 2026

## Context

CodeBuild returns AccessDeniedException; SSM needs no SSH or new role; instructor approved 18 Nov.

## Decision

EC2 build host driven by SSM Run Command.

## Alternative rejected

CodeBuild.

## Consequences

- CodeBuild returns AccessDeniedException.
- SSM needs no SSH or new role.
- Instructor approved 18 Nov.
