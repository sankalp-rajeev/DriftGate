# ADR-010: SNS email approval via Lambda function URL with one-time token

Status: Accepted, 18 November 2026

## Context

Keeps a human in the loop without a new role; untested in Lab.

## Decision

SNS email approval via Lambda function URL with one-time token.

## Alternative rejected

No approval; Step Functions.

## Consequences

- Keeps a human in the loop without a new role.
- Untested in Lab.
