# D7 pre-registration, 26 Nov 2026

This post-demo study adds D7 to the original [pre-registration](preregistration.md).
It uses the current fault definitions in `faults/faults.yaml`, SHA-256
`81f02e436c4842a30bbca7c7780cf5748c61a83ed6f9e1f32372ba1f67a7ff01`.
F8 replays the recorded b12557 engine bump
(`b94959a64d011915d77a5381c7d4846dcda99530`). The baseline and other fault definitions
are the ones used in the [reported study](../results.md).

D7 embeds the D3 greedy continuation for each prompt with seed 0 and the same D3 request
parameters. The encoder is Compendium Labs' F16 BGE Small EN v1.5 GGUF from
`serving/models.yaml`, served by the baseline pinned llama.cpp engine even when F8
changes the generation engine. Compare pairs by prompt ID, with cosine similarity 1
for two blank continuations and 0 for one blank continuation. Record mean and linearly
interpolated p5 similarity. The gating statistic is 1 minus p5 similarity. A request
failure counts as a detection in every budget prefix that contains the failed prompt.

On Ubuntu, use the existing L1, L2 and L3 D3 prefixes. On the t3.large, calibrate
the deployed L1 budget using D3 and D7 only. Each platform uses its own archived baseline
and embedding reference, with 20 fresh identical server starts for calibration and 10
further starts held out. At each level set the upper threshold to the maximum calibration
statistic. A value strictly above the threshold fires. Calibration errors prevent fitting;
held-out errors count as false alarms. The per-detector bound is 1/21 under exchangeability.
Report held-out counts and the 95% Clopper–Pearson interval. The original eligibility rule
allows at most one held-out alarm in ten. The measured rate and interval will be reported
alongside the 5% project target.

The Ubuntu matrix repeats F1–F9 with the original repetition rule. Report each detector's
detections over completed runs, including misses. The analysis uses `analysis/d7_runs.py`,
`analysis/calibrate.py` and `analysis/matrix.py`. Only the Lab L1 calibration supplies the
deploy threshold. D7 has unit weight in the existing maximum-of-detector-scores GateScore.
Measure D7's incremental ValidateService wall time, including encoder startup and shutdown.
