# Task T-03: Repository skeleton

Read `AGENTS.md` and `PRD.md` first. Work on branch `t-03-repo-skeleton`. Do not write any detector, serving, fault or AWS code in this task.

## Goal

Create the empty but working skeleton of the DriftGate repository, so later tasks only add code into a fixed layout with tests, lint and CI already running.

## Decisions already made (do not change them)

- Python 3.11+, managed with `uv`. Single `pyproject.toml` at the root. Top-level packages: `gate`, `faults`, `analysis`, `orchestrator` (each with `__init__.py`). No `src/` layout.
- Dev dependencies only for now: `pytest`, `ruff`. No runtime dependencies yet.
- Ruff: line length 100, target py311, rules `E`, `F`, `I`, `B`, `UP`.
- License: MIT.

## Create these files

1. `pyproject.toml`: project `driftgate`, version `0.1.0`, `requires-python = ">=3.11"`, the four packages above, dev dependency group with pytest and ruff, ruff and pytest config.
2. `Makefile` with targets `setup` (`uv sync`), `test` (`uv run pytest -q`), `lint` (`uv run ruff check . && uv run ruff format --check .`), `fmt` (`uv run ruff format . && uv run ruff check --fix .`). Add a `help` target that lists them, as the default.
3. Package folders with `__init__.py`: `gate/`, `faults/`, `analysis/`, `orchestrator/`.
4. Empty folders kept with a one-line `README.md` that states the folder's purpose and the PRD requirement ids it will hold: `serving/` (FR-01 to FR-03), `deploy/` (FR-16 to FR-19, FR-21), `deploy/hooks/`, `deploy/cloudformation/`, `observability/` (FR-22 to FR-24, FR-29), `iam/` (NFR-06), `docs/prereg/` (FR-11; must say: "frozen after the pre-registration commit; never edit").
5. `tests/test_smoke.py`: imports each of the four packages and asserts they import. This is the only test in this task.
6. `docs/adr/ADR-001.md` to `docs/adr/ADR-010.md`: one file per row of the ADR table in PRD Section 8. Use this template and copy the decision, alternative and reason from the PRD; do not invent new reasoning:
   ```
   # ADR-00N: <decision>
   Status: Accepted, 18 November 2026
   ## Context
   <one or two sentences from the PRD reason>
   ## Decision
   <decision>
   ## Alternative rejected
   <alternative>
   ## Consequences
   <reason, restated as consequences>
   ```
   ADR-007 must note that it supersedes the v1.0 decision "CodePipeline V2".
7. `docs/architecture.md`: the mermaid diagram from PRD Section 8, plus a short paragraph per layer (evidence, delivery) taken from PRD Section 1.
8. `docs/lab-constraints.md`: title "Lab Constraints and Equivalences" and an empty table with columns Constraint | What the Lab does | Equivalent used | Evidence | What is lost | Enforced or documented. Add one row per item listed in FR-28, with the first two columns filled from PRD Section 14.2 and the rest left as `TBD`.
9. `GLOSSARY.md`: definitions, one or two lines each, for: A/A run, fault (F1 to F9), detector (D1 to D6), gate verdict, bundle, manifest, run record, panel, prompt budget, false-alarm rate (FPR), pre-registration, ValidateService. Take meanings from the PRD only.
10. `ATTRIBUTION.md`: a table with Name | Use | License | Link for llama.cpp, ggufdoctor, Model Equality Testing, infer-check (prior art), Qwen2.5-1.5B-Instruct and Qwen2.5-0.5B-Instruct. Put `TBD (verify)` for any license you cannot read from a file in this repo. Do not look licenses up.
11. `README.md`: one-paragraph summary from PRD Section 1, a "Status" line ("Skeleton only, T-03"), and the `make` commands.
12. `.gitignore`: Python defaults, `.venv/`, `models/`, `artifacts/`, `runs/`, `*.gguf`, `*.bin`, `.env`, `.scratch/`.
13. `.github/workflows/ci.yml`: on push and pull request, Ubuntu, install `uv`, run `make setup`, `make lint`, `make test`.
14. `LICENSE`: MIT, copyright 2026 Sankalp Rajeev.

## Do not touch

- `git ls-files | grep -E '\.gguf$|\.env$'` returns nothing.
- CI workflow is valid YAML and runs the same three make targets.
- Every folder in the AGENTS.md layout exists.
